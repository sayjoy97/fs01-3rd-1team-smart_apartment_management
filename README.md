## 🗓️ 4. 프로젝트 일정

- **1~2주차 (설계)**: 요구사항 정의, 기능 우선순위 설정, DB/ERD 및 API 명세서 작성
- **3~5주차 (개발)**: AI 모델 학습, 백엔드 API 및 프론트엔드 개발, 하드웨어 회로 구성
- **5~7주차 (통합)**: AIoT 하드웨어-소프트웨어 연동 테스트, 아파트 모형 구축 및 시스템 안정화
- **7주차 (마무리)**: 시연 영상 제작, 결과 보고서 및 발표 자료 작성

## 🏗 5. 시스템 아키텍처

### 🧰 기술 스택

- **Hardware**: Arduino, Raspberry Pi 4, various IoT Sensors (RFID, Ultrasonic, Sound, Power etc.)
- **Frontend**: React, React Native, Vite
- **Backend**: Java Spring Boot, Spring Security, JPA, Spring Integration MQTT
- **AI/ML**: YOLOv8, EasyOCR/PaddleOCR, KoBERT
- **Database**: MariaDB (DBeaver)
- **Communication**: MQTT (Mosquitto), I2C, Serial Communication

### 📗 ERD
![main](https://github.com/user-attachments/assets/e7fbfa79-fe4d-4366-b4cc-0fd6ed09028a)


### 💡 주요 기능 요약

1. **엘리베이터 관리**: 실시간 위치 표시, 스텝 모터 시뮬레이션, LCD 내부 정보 출력
2. **층간소음 관리**: 진동/사운드 센서 기반 데이터 수집 및 기준 초과 시 관리자 알림
3. **에너지 관리**: 세대별 전력 소비 패턴 분석 및 이상 사용 탐지 대시보드
4. **입주민 출입**: RFID/키패드 기반 보안 출입 및 외부인 세대 호출 시스템
5. **차량 출입**: AI 번호판 인식 기반 등록 차량 자동 개방 및 외부 차량 요금 부과
6. **민원 관리**: AI 기반 민원 내용 요약 및 처리 이력 통합 관리

## ⚠️ 6. 미 해결 문제 및 해결 방안

| 문제점             | 원인                              | 해결 방안                                                       |
