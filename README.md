## 🏗 5. 시스템 아키텍처

### 🧰 기술 스택

- **Hardware**: Arduino, Raspberry Pi 4, various IoT Sensors (RFID, Ultrasonic, Sound, Power etc.)
- **Frontend**: React, React Native, Vite
- **Backend**: Java Spring Boot, Spring Security, JPA, Spring Integration MQTT
- **AI/ML**: YOLOv8, EasyOCR/PaddleOCR, KoBERT
- **Database**: MariaDB (DBeaver)
- **Communication**: MQTT (Mosquitto), I2C, Serial Communication

### 📗 ERD
<img width="2709" height="1689" alt="erd" src="https://github.com/user-attachments/assets/dfd251b6-9008-46e6-acb3-4097126b9a67" />

### 💡 주요 기능 요약

1. **엘리베이터 관리**: 실시간 위치 표시, 스텝 모터 시뮬레이션, LCD 내부 정보 출력
2. **층간소음 관리**: 진동/사운드/충격 센서 기반 데이터 수집 및 기준 초과 시 이벤트 처리와 관리자 알림
3. **에너지 관리**: 세대별 전력 소비 패턴 분석 및 원격제어와 이상 사용 탐지 대시보드
4. **입주민 출입**: RFID/키패드 기반 보안 출입 및 관리자 원격 호출 시스템
5. **차량 출입**: AI 번호판 인식 기반 등록 차량 자동 개방 및 외부 차량 요금 부과
6. **민원 관리**: AI 기반 민원 내용 요약 및 처리 이력 통합 관리

## ⚠️ 6. 미 해결 문제 및 해결 방안

| 문제점                     | 원인                              | 해결 방안                                                       |
| :----------------- | :-------------------------------- | :-------------------------------------------------------------- |
| OCR 인식 정확도    | 모형차 사용 및 카메라 화질 한계          | 실제 학습한 YOLO모델 인식 저하해 모형차도 자동차로 인식할 수 있게 개선<br/>YOLO모델 인식 실패해도 OCR모델 실행될 수 있게 개선 |
| 실시간 데이터 지연 | MQTT 브로커 부하 및 네트워크 지연 | 메시지 QoS 설정 최적화 및 경량 데이터 포맷(JSON) 사용           |
| 엘리베이터 호출 취소 | 호출 방법(외부 버튼, 내부 버튼)에 관계 없이 호출 힙을 동시에 관리<br/>내부 버튼 호출 취소 시 힙에서 해당 층 호출 취소<br/>힙에서 제거되면서 외부 버튼 호출도 취소 됨 | 호출 방법에 따라 각각의 힙으로 관리 |
